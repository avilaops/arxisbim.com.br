# Arxis | Lote visual de setembro de 2026

Artes criadas a partir do cronograma de 360 dias. Cada pauta recebeu uma linguagem própria, mantendo a assinatura Arxis por meio da paleta azul petróleo, azul profundo, branco e laranja, além do símbolo oficial aplicado nas versões finais.

| ID | Pauta | Linguagem | Formato | Arquivos |
|---|---|---|---|---|
| P01 | Conheça a Arxis: visualize, analise, decida | Editorial arquitetônica com modelo BIM | 1080 x 1080 | `final/P01-arxis-apresentacao-1080x1080.png` |
| P02 | BIM em 30 segundos | Ilustração 3D leve e dinâmica para Reel | 1080 x 1920 | `final/P02-bim-em-30-segundos-reel-1080x1920.png` |
| P03 | Modelo 3D e informação | Colagem técnica de blueprint, geometria e dados | 1080 x 1350 | `final/P03-modelo-3d-informacao-carrossel-1080x1350.png` |
| P04 | Qual é o maior gargalo? | Humor visual com arquiteto sobrecarregado e Arxis organizando o caos | 1080 x 1080 | `final/P04-gargalo-rotina-meme-1080x1080.png` |

A pasta `raw` preserva as imagens geradas antes da assinatura final. A pasta `final` contém as versões prontas para revisão, texto e publicação.
