# Metadados editoriais Arxis

`posts.json` contém o registro por pauta com título, descrição, legenda, hashtags, caminho do asset e texto alternativo.

Os arquivos em `../previews/` são folhas de contato para revisão visual mensal. Os arquivos `final/` são os prontos para publicação; `raw/` preserva as imagens geradas antes da aplicação do selo oficial Arxis.
