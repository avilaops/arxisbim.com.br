PRÉ-DEPLOY (Execute Localmente)
═══════════════════════════════════════════════════════════════

[_] 1. Gerar pepper seguro
    node -e "console.log(require('crypto').randomBytes(48).toString('base64url'))"
    Copiar output

[_] 2. Configurar .env
    echo "API_TOKEN_PEPPER=<pepper_gerado>" >> backend/.env

[_] 3. Executar setup automático
    bash backend/setup.sh

[_] 4. Verificar pré-deploy
    bash backend/verify-production.sh
    Resultado: ✅ Todos os checks passaram

[_] 5. Build
    npm run build

[_] 6. Migrations
    npm run migrate

[_] 7. Testar localmente
    npm run dev
    - Acessar http://localhost:5173/account
    - Criar um token test
    - Testar curl com o token

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

Erro: "API_TOKEN_PEPPER não configurado"
→ Adicione ao .env: API_TOKEN_PEPPER=<valor>

Erro: "API_TOKEN_PEPPER muito curto"
→ Regenere com: node -e "console.log(require('crypto').randomBytes(48).toString('base64url'))"

Erro: "401 Invalid token format"
→ Token não começa com arx_live_ ou arx_test_

Erro: "403 Forbidden - Required scopes"
→ Criar novo token com escopos necessários

Erro: "Database connection failed"
→ Verificar DATABASE_URL em .env e conexão PostgreSQL
